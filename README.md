# AgriHealthMap

## Описание

AgriHealthMap - это комплексная система для мониторинга и анализа состояния сельскохозяйственных полей. Проект использует спутниковые снимки и модели машинного обучения для решения таких задач, как сегментация полей, классификация культур и прогнозирование индекса NDVI.

## Особенности

*   **Сегментация полей:** Автоматическое определение границ полей на спутниковых снимках.
*   **Классификация сельскохозяйственных культур:** Определение типов культур, выращиваемых на полях.
*   **Прогнозирование NDVI:** Прогнозирование индекса NDVI (нормализованный относительный индекс растительности) для оценки здоровья растений.
*   **Аутентификация и управление базой данных:** Безопасный доступ и управление данными.
*   **Статистический анализ:** Инструменты для статистического анализа данных.

## Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/olegkeatzin/AgriHealthMap.git
    ```
2.  Перейдите в директорию проекта:
    ```bash
    cd AgriHealthMap
    ```
3.  Установите зависимости. Проект использует `uv` для управления зависимостями. Вы можете найти их в файле `pyproject.toml` и `uv.lock`.
    ```bash
    pip install uv
    uv sync
    ```
4. Положите модели в папку /models. Модели доступны по адресу [Яндекс.Диск](https://disk.yandex.ru/d/xrKrm8aMnHkE1A)
5. Убедитесь, что вы используете правильную версию Python, указанную в файле `.python-version`.

## Как использовать

1.  Создайте .env файл с следующими полями:
     ```bash
    SH_CLIENT_ID = 
    SH_CLIENT_SECRET =
    CROP_MODEL_PATH = 
    FIELD_MODEL_PATH = 
    NDVI_MODEL_PATH =
    ```
2.  **Запуск:** Запустите главный файл проекта:
    ```bash
    uvicorn main:app --reload
    ```
3. В консоли будет указан URL на котором запущен сервер
